# MVP-2025-Engenharia-de-Dados

## Resumo do Projeto

O projeto localizado na pasta **La liga - Pipeline** consiste em um pipeline de dados desenvolvido para processar e transformar informações relacionadas à La Liga. O pipeline utiliza notebooks de exploração, scripts de transformação de tabelas e funções utilitárias para organizar e enriquecer os dados. A configuração do pipeline é gerenciada por arquivos YAML, garantindo controle de versão e fácil manutenção. O objetivo principal é fornecer uma base de dados estruturada e confiável para análises sobre o campeonato, facilitando a geração de insights e relatórios para a equipe de engenharia de dados.

## Tecnologias Utilizadas

- Databricks
- Python
- SQL
- Git
